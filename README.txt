PICASSO SUNUM WEB PAKETİ

Dosyalar:
- index.html: Bağımsız, tarayıcı tabanlı slayt görüntüleyici
- slides/: Sunumdaki 18 slaydın görsel çıktıları
- process-videos.mp4: Sunumdaki 108 saniyelik video
- Picasso_Sunum.pptx: Orijinal PowerPoint dosyası (indirme yedeği)

Vercel/GitHub Pages yayını:
1. Bu klasörün içindeki TÜM dosya ve klasörleri GitHub deposunun kök dizinine yükleyin.
2. Vercel'de bu depoyu import edip deploy edin. Framework: Other; Build Command boş; Output Directory: . (root).
3. Canlı sayfada ok tuşlarını, tam ekranı, video slaydını ve PPTX indirmeyi test edin.

Not: Tarayıcılar PPTX dosyasını doğrudan PowerPoint gibi yerel olarak çalıştırmaz. Bu görüntüleyici slaytların görsel çıktısını kendi arayüzünde gösterir ve video bölümünü yerel MP4 dosyasıyla oynatır. Bu nedenle geçişler/animasyonlar ve PPTX içindeki diğer özel PowerPoint etkileşimleri birebir taşınmayabilir. Hiçbir harici JS kütüphanesi veya çevrimiçi PowerPoint görüntüleyicisi kullanılmaz. Canlı siteyi açmak için internet gerekir; dosyalar sayfayla aynı siteden yüklenir.
